# Autotask Datto Reporting - Documentation Home

This is the single documentation root for the reporting platform. Read the
architecture write-up first if you are new to the project; it explains the
problem, the life of a report request, each layer and the decisions behind
them. Then pick the branch that matches the work: the server, the client, or
operations. Each branch has one hub per source directory, a focused page for
every behavior-owning module, and a grouped inventory for tests, configuration
and assets, with every page linking the exact source file it describes.

- Server pages mirror `server/`: routers, services, repositories,
  integrations, core, demo and tests.
- Client pages mirror `client/src/`: api, store, hooks, components, pages
  (with one folder per report) and utils.
- Operations covers CI, the Compose stacks and the screenshot tooling.
